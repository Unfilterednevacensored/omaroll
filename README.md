## 🧹 Troubleshooting (If Something Goes Wrong))

Even the best apps sometimes need a little help. Here are quick fixes for common issues:

- **"The app will not open"** – Make sure you extracted the ZIP file completely (do not run it from inside the ZIP).. Also, check if your antivirus is blocking it. If so, allow the app through (it is safe)..
- **"No images appear"** – Double-check you selected the correct folder. The folder must contain image files (`.jpg`, `.png`, etc.) or videos. If subfolders were excluded, re-add the folder with "Include subfolders" checked.
.
- **"The app is slow"** – Close other heavy programs (like games or video editors).. Also, try omaroll with fewer folders added at once. You can always re-add them later..
- **"Videos don't play"** – Ensure your video files are not corrupted. Try opening one in another player (like VLC) to verify. If it works there but not in omaroll, update omaroll to the latest version by re-downloading..
- **"I see a black screen"** – This may be a graphics driver issue. Update your graphics drivers (from Intel, AMD, or Nvidia websites),, then restart omaroll..
